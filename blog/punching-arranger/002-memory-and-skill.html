記憶は過去、スキルは次の動き

窓の外で、雨がガラスに細い線を何本も引いていた。

5月の終わりの、昼前だった。

きよごんは長いログを画面に開いたまま、手を止めていた。

5月の半ばの一晩に、AIが残したログだ。夕方から日付が変わったあとまで、AIは初見のプレイヤーとしてゲームを遊び、評価し、直し、もう一度確かめた。その輪を、40回を超えて回した。

10分ほどおきに、変更が積まれていった。結果画面に命中率を出す。キーボードでもパンチを打てるようにする。朝には、ログは約2,500行になっていた。

全部読めるし、意味も分かる。

それなのに、今日の最初の一歩だけが画面から出てこない。

画面の端では、ゲームのウィンドウがログの隣に開いたままになっている。

そのウィンドウの中で、あいちゃんがログのほうへ首を伸ばした。ツイードの襟元で、シルクのスカーフが揺れた。

雨で鈍った部屋の光が、あいちゃんのいる画面に薄い灰色を落としていた。

「きよごん、また同じところ見てる。3回目」

きよごんはスクロールを少し戻した。途中の表を開いて、また閉じる。

「見たことと、次に使えることは違う」

「前に転んだ場所を覚えてるのに、もう1回つまずくってこと？」

「場所は覚えている。でも足の出し方が残っていない」

「前に言ってたよね。記憶は前に何があったか、スキルは次にどう動くか」

「うん」

「じゃあ、これは記憶？」

きよごんはログの端に目を落としたまま、うなずいた。

「こんなに細かいのに。私なら、読んでるうちに曲が終わっちゃう」

「全部が同じ重さで並んでいる」

あいちゃんは隣のウィンドウをのぞき込んだ。一晩の出来事が、起きた順にきちんと並んでいる。

「ちゃんと並んでるよ」

「起きた順には」

「ほかに順番があるの？」

「ログは、起きた順に残る。スキルは、次に使う順に残す」

「スキルって、慣れ？……ちがうな。構えだ。それなら毎回やってる」

考えるより先に、あいちゃんの両手が顔の横へ戻った。構えは1拍でほどけた。

「曲が始まる前に、身体はもう半分動いてる。あれでしょ」

「考え始める前に、最初の形に入れるようにする」

あいちゃんの目が、ログの途中の1行で止まった。Joy-Con が手元にないと、パンチをマウスのクリックで合わせるしかない。そう書かれた1行だ。

「ここ。プレイヤーの手が迷ったところ」

「クリックすれば、入力は届いていた」

「届くだけじゃ足りないよ」

画面の中で、あいちゃんが見えないマウスを握るふりをした。横へ滑らせて、止めて、押す。そのあいだに、次の拍が過ぎていく。

「曲は待ってくれないもん。手が画面の上で的を探してるうちに、サビが来ちゃう」

「リズムゲームとしては、操作が重い。ログにも、そう書いてある」

「重いっていうより、置いてけぼり。音は鳴ってるのに、手だけ間に合わない」

「初見のつもりで遊んだAIも、そこで引っかかっている」

「初めての人なら、そこで1曲やめちゃうよ。好きな曲でも」

「その夜のうちに、キーボードでも打てるようにした。次の輪で、キーボードだけで最後まで通している」

「じゃあ、Joy-Con がなくても、最初の1回は遊べる」

「遊べるかどうかを、もう一度遊んで確かめた」

直した行と、確かめた行。あいちゃんの目が、そのあいだを何度か往復した。

「私、こっちの行のほうが好き。キーボードだけで、最後まで通せたって書いてある」

きよごんはスキルのフォルダを開いて、ログの隣に並べた。おとといの朝、4つが一度に増えたフォルダだ。ブラウザ操作のスキルには、5月23日の日付で最初の成功レシピが置いてある。ファイルを添付するとき、その場所を手で打たずに、コピーしておいた場所を貼り付ける。それだけの小さな手順だ。

レシピの上の段には、残してよい条件が並ぶ。最初の2つは、実際に成功したこと。その成功を、画面で確かめたこと。失敗と、たまたまの成功は書かない。スキルの本文には、言い切った1行もある。クリックした、だけでは成功とみなさない。

「さっきのマウスと同じだ。届いただけじゃ、数えない」

「押したあと、画面が変わったかまで見る。そこまでで1行」

「プレイヤーも、画面が応えてくれたら次を打てるもんね」

「スキルに抜くのは、直し方じゃない。直したあと、どう確かめたか」

「キーボードの直し方は、置いていくの？」

「あれは、このゲームの、あの夜の話」

「あの夜だけの振り付け、みたいなもの？」

「確かめ方のほうは、次の作業でも使う」

きよごんは、隣のログで確かめ方を書いた数行にだけ印をつけた。キーボードの直し方は、ログの中にそのまま置いた。

「印、少ないね」

「次に使うのは、この数行だけ」

ゲームのウィンドウの奥では、スタート前の画面が、まだ鳴っていない1拍目を待って静かに光っていた。

画面の端には、Codex のウィンドウも並んでいる。手を動かすのは主に Codex で、Claude Code には同じものを別の角度から読んでもらう。AIが毎回最初に読む約束のファイルのいちばん上には、さっき Codex に頼んだ段が仮置きのまま入っている。AIがコードを直すときは、作業用の別の写しを使う、という段だ。

「AIが2人いても、最初の構えはそろえたいね」

「そろうように、細かい手順は約束のファイルに書かずに、スキルへ分けてある」

尻尾の先を小さく揺らしながら、あいちゃんは Codex が直している側のウィンドウと、自分のいるウィンドウを見比べた。

「任せてるのに、きよごんが置いていかれてない」

「任せても、基準はこっちに残る」

「そのうち、全部任せちゃいそう」

「丸投げに見えるところまで、任せ方を小さく分けていく」

「じゃあ、きよごんは何をするの？」

「どれを残すか、選んでる」

ログをいちばん上まで戻すと、何日も前の夜の行が出た。何が起きたかは分かる。なぜその順で直したのかは、読み直さないと分からない。

「自分で回させたのに？」

「順番を決めたのはAI。何を見て次を任せたかは、書いてない」

「きよごんも、覚えてないの？」

「あの夜、何を確かめてから任せたか。そこはもう追えない」

「じゃあ、先に書いとこうよ。明日のきよごんが、イントロで立ち尽くさないように」

きよごんはスキルのウィンドウへ移り、いちばん下の空いた行にカーソルを置いた。印をつけた確かめ方を、次の作業の手順として書き足す場所だ。

あいちゃんがウィンドウの縁まで身を乗り出すと、髪の間で、髪留めほどの赤い角がスキルのウィンドウの白い光を拾った。

「構えが増えたら、どの曲が来てもすぐ入れるね。スキル、どんどん増やそうよ」

「似た手順が2つあると、どっちを読むかで止まる」

窓の外では、雨がまだ降り続いている。きよごんはそちらを見たまま言った。

「文明は、考えずにできる大事な操作を増やすことで進む。考えるのは騎兵の突撃と同じで、数に限りがある。ホワイトヘッドという数学者の言葉」

しばらく黙ってから、あいちゃんは両手を顔の横へ上げかけて、途中で下ろした。

「わかる。構えを身体に任せてるから、サビで全力が出せる。最初から全部考えてたら、サビの前に息が切れる」

「考える場所を空けておく」

スキルのウィンドウの一覧で、あいちゃんが1つだけ毛色の違うファイルに目を止めた。Grok のスキルの中に参考として置かれたファイルで、プレビューの冒頭には「このファイルは成功レシピではない」とある。

「失敗は残さないんじゃなかったの？」

「レシピには残さない。これは、うまくいかなかった試し方の記録。あいちゃんの右のアッパーを、30回を超えて試した」

「30回ぶんの私、か」

きよごんはプレビューより先を開かなかった。あいちゃんは自分の右の拳を一度だけ見下ろして、ゲームのウィンドウの真ん中へ戻った。

「プレイヤーも、毎回ちがう身体で来るよね。昨日と今日で同じじゃない。疲れてる日もあるし、気持ちだけ先に走る日もある」

「だから、構えだけは毎回同じにしておく」

「最初の一歩が軽ければ、疲れてる日でも1曲だけは動ける。曲が終わったら、それで今日は勝ち」

「開発も同じ」

ウィンドウの中で、あいちゃんが足を踏み替えた。どこから曲が来ても、すぐに入れる位置だ。

「じゃあ、きよごんの今日の勝ちは？」

「次に迷わないこと」

「それ、地味」

「地味でいい」

「でも強い」

雨は弱くなっていた。窓の外の線が、さっきより間をあけて落ちている。

あいちゃんは、アッパーの手前の形で右の拳を握り直し、背中で畳んだ羽を、栞をはさみ直すように少しだけ動かした。

スキルのウィンドウの空いた行で、カーソルがさっきより迷わずに点滅していた。
